# Computer Networks Summary

A collection of practical assignments completed for the Computer Networks course (Jaringan Komputer), covering network design, configuration, routing, network services, traffic analysis, and security.

**Contribution:** Individual coursework. Completed all practical assignments from Module 1 to Module 5.

## Modules

### Module 1 — Network Traffic Analysis
[Repository](https://github.com/naufalhakims/jarkom-modul-1-IT42-2024)

- DNS queries and domain/IP resolution.
- Source and destination IP addresses and ports.
- TLS/JARM fingerprinting.
- Netcat connections.
- FTP and HTTP stream analysis.

### Module 2 — Network Topology and Services
[Repository](https://github.com/naufalhakims/jarkom-modul-2-IT42-2024)

- Multi-node network topology and router configuration.
- BIND9 DNS master/slave.
- Static IP addressing, routing, and NAT using iptables.
- Apache and Nginx web servers.
- PHP and load balancing.
- Apache Benchmark.

### Module 3 — DHCP and Web Infrastructure
[Repository](https://github.com/naufalhakims/jarkom-modul-3-IT42-2024)

- DHCP server and relay configuration.
- BIND9 DNS.
- Nginx load balancing and PHP-FPM workers.
- MariaDB.
- Firewall rules and htpasswd-based access restrictions.

### Module 4 — Subnetting and Routing
[Repository](https://github.com/naufalhakims/jarkom-modul-4-IT42-2024)

- Network topology design.
- VLSM subnet planning.
- IP address allocation.
- Router interface configuration.
- Static routing.

### Module 5 — Network Security and Access Control
[Repository](https://github.com/naufalhakims/jarkom-modul-5-IT42-2024)

- Subnet allocation and static routing.
- NAT/SNAT using iptables.
- Firewall and access-control rules.
- Network access policies.
- Nmap port-scan detection and blocking.
- Netcat connectivity validation.

## Skills and Technologies

- **Networking:** IP addressing, subnetting, VLSM, routing, NAT, SNAT, client-server networking.
- **Network Services:** BIND9, DHCP, Apache, Nginx, PHP-FPM, MariaDB.
- **Network Security:** iptables, firewall configuration, access control, traffic analysis.
- **Tools:** Netcat, Nmap, Apache Benchmark, JARM.

## About

These repositories document hands-on exercises in designing, configuring, analyzing, and securing computer networks throughout the course.
